# 互動式閱讀測驗網頁 (reading-quiz)

使用者給一篇文章 → 產出一個 `<文章標題>閱讀測驗.html`。

版面、顏色、互動方式都固定在 `assets/template.html`，**不要改範本、不要自己重寫網頁**。Claude 只負責寫一份資料檔（JSON），再跑腳本套進範本。完整範例：`examples/會說話的路.json`，每次動手前先讀它。

## 對象（預設）

國中學習障礙或閱讀理解較弱的學生，需要報讀支持。使用者指定年級或狀況時，就照使用者說的調整題目難度，版面不變。

## 流程

1. **讀文章、確認段落**：照原文的自然段切成 `paragraphs`，一段一個字串。不要改寫原文，只修正明顯的錯字，並把半形逗號「,」換成全形「，」（報讀斷句比較自然）。
2. **出題**：預設 4 題，使用者指定題數就照做（3～6 題為宜）。寫法見下方「出題原則」。
3. **寫資料檔**：在 scratchpad 寫 `<標題>.json`，欄位照下方規格。
4. **產生網頁**：
   ```bash
   python ~/.claude/skills/reading-quiz/scripts/build_page.py <標題>.json "<輸出資料夾>/<標題>閱讀測驗.html"
   ```
   輸出資料夾：使用者指定的位置；沒指定就放在目前工作資料夾。腳本會檢查正確答案是否在選項裡、段落是否為空，有錯就修資料檔重跑。
5. **檢查**：在瀏覽器打開網頁，用 javascript 點「閱讀文章」，確認第一段出現、顯示「第 1 / N 段」、按鈕顯示倒數、姓名欄收起；再把所有段落顯示出來、開始作答，確認文章收起、右上角出現「顯示文章」。按一下確認原文出現（桌機左右並排）再收起。第 1 題先選一個錯的答案並提交，確認文章自動打開、出現「提示」框、對應段落被框起來、錯的選項變灰劃線；再選錯一次，確認證據句標成橘色；最後選正確答案，確認出現「答對了！你用提示找到了答案」和詳解，且「下一題」在原本「提交答案」的位置。
6. **回報**：附上檔案連結，列出每一題的題目、正確答案、它考的層次（擷取／推論／主旨）和證據段落，並提醒使用者**開喇叭試聽報讀**、確認題目答案。

## 資料檔規格

| 欄位 | 內容 |
|---|---|
| `title` | 文章標題，顯示在頁面最上方，也用在網頁分頁標題 |
| `source` | 出處，例如 `"改編自翰林非讀book"`；沒有就寫 `""`，網頁就不顯示 |
| `waitSeconds` | 每段出現後要等幾秒才能看下一段。預設 20；段落很短或題目簡單用 10；使用者說不要等就寫 0 |
| `theme` | 配色。`"minimal"`（簡約：墨藍、米白紙色、橘色重點，思源黑體＋思源宋體標題，**預設**）或 `"classic"`（原本的藍綠色版本）。使用者沒指定就用 minimal |
| `mode` | `"practice"`（練習：答錯先給提示，預設）或 `"test"`（測驗：答完立即公布答案）。也能在設定面板的「老師設定」切換，開始作答後鎖住 |
| `paragraphs` | 文章段落，字串陣列 |
| `questions` | 題目陣列，每題 `{question, options, correctAnswer, explanation}` |

每一題：
- `options`：`{"A": "...", "B": "...", "C": "...", "D": "..."}`，固定四個選項
- `correctAnswer`：正確選項的代號，例如 `"B"`
- `explanation`：詳解，**一定要指出答案在第幾段**，並引用原文句子，例如：「文中第一段提到，科學家推估其出生於明朝，於是命名『明』。」
- `evidence`：練習模式的提示來源，`{"paragraph": 段落編號(從 1 開始), "sentence": "原文中的證據句"}`。`sentence` **必須從原文直接複製**（可以只取其中一段，標點可省略），腳本會檢查它是否真的在那一段。主旨題就挑最能支持答案的那一句。每一題都要寫。

## 畫面流程

1. **閱讀**：開頭有使用技巧和「姓名／座號」欄；按「閱讀文章」後姓名欄收起，段落逐段出現，按鈕上方顯示「第 n / N 段」和「點句子就能聽」。
2. **作答**：按「讀完了，開始作答」後文章收起，只剩題目。右上角「顯示文章」可開關原文：桌機左文右題並排，手機蓋滿全螢幕（文章上方有「回到題目」）。每換一題文章會自動收起。練習模式給提示時會自動打開文章並捲到該段。
3. **結果**：計分、每題明細、下載 CSV。

右上角齒輪是設定：報讀語速、字體大小、行距；下方「老師設定」有作答模式（開始作答後鎖住）和「複製文章與題目」。

## 練習模式的提示順序

學生答錯時，那個選項會變灰、劃線並鎖住，然後依序給提示（提示框前面有橘色「提示」標籤）：

1. 第一次答錯：「回到第 N 段再讀一次」，文章自動打開，該段加上橘色外框並捲到畫面中。
2. 第二次答錯：把 `evidence.sentence` 對應的句子標成橘色。
3. 第三次答錯：公布正確答案和詳解。

結果頁會分開計算「第一次就答對」和「用提示後答對」，並列出每題的作答次數、回看文章次數與秒數。

## 作答紀錄

- 閱讀開始前有「姓名／座號」欄（選填）。如果網頁在教學平台裡、平台有提供 `window.spedStudentId`，就會自動填入。
- 結果頁可以下載兩個 CSV（含 BOM，Excel 開啟不會亂碼）：
  - **作答摘要**：每題一列，包含作答順序、作答次數、使用提示數、回看文章次數、第一次是否答對、作答秒數。
  - **操作紀錄**：每個動作一列，包含顯示段落、朗讀段落／句子、劃重點、朗讀題目／選項／詳解／提示、作答、給提示、開啟／關閉文章（學生自己按或提示自動打開）、調整語速／字體／行距，並附上時間和經過秒數。
- 每次完成也會存一份到瀏覽器的 `localStorage['reading_quiz_records']`（保留最近 50 筆），只存在那台電腦的那個瀏覽器裡。

## 出題原則

- **由淺到深排序**：前面是擷取訊息（答案直接寫在文中），中間是推論或比較（要整合兩處以上的資訊），最後一題問主旨或作者想表達的意思。
- **正確答案平均分配**在 A～D，不要都放同一個位置。
- **錯誤選項要有道理**：用文中出現過但不符題意的詞、常見誤解，或把因果顛倒，不要出明顯荒謬的選項。
- 「何者不正確」這類否定題全份最多 1 題，題目裡的「不」要保留原樣讓報讀唸得出來。
- 題目和選項用學生看得懂的白話，句子短；選項長度盡量接近，避免最長的那個就是答案。
- 不考文章沒提到的背景知識。

## 不要做的事

- 不要改範本的版面、按鈕文字和頁尾授權文字；配色只用 `theme` 切換，不要另外寫顏色。
- 不要把文章內容寫進範本，所有文字都放在資料檔。
- 使用者想要新功能時，先跟使用者確認，再改 `assets/template.html`，並更新這份說明。
